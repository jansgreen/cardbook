Privacidad

Politica de privacidad

Cardbook ayuda a empresas y profesionales a crear, compartir y administrar tarjetas digitales, perfiles de negocio, alianzas y contactos guardados.

Informacion que recopilamos

Recopilamos la informacion que el usuario proporciona al crear una cuenta, empresa, perfil digital, tarjeta de presentacion, publicacion, alianza o elemento guardado en Book. Esto puede incluir nombre, email, telefono, empresa, cargo, sitio web, direccion, redes sociales, imagenes y preferencias de idioma.

Uso de la informacion

Usamos la informacion para operar Cardbook, autenticar usuarios, mostrar tarjetas publicas, generar enlaces y codigos QR, administrar empresas, facilitar alianzas, guardar contactos en Book, medir interacciones y mejorar la experiencia del producto.

Informacion publica

Los perfiles de negocio, tarjetas digitales y tarjetas de presentacion creadas para compartir pueden ser visibles publicamente mediante enlaces, codigos QR o vistas publicas. El usuario controla que informacion decide publicar en esas tarjetas.

App movil

La app movil Cardbook se conecta a la API de Cardbook para iniciar sesion, consultar informacion de cuenta, administrar empresas, tarjetas, Book, alianzas y revisar actualizaciones. La app puede abrir aplicaciones del sistema como telefono, correo, navegador, WhatsApp o mapas cuando el usuario toca una accion.

Seguridad

Cardbook usa autenticacion por tokens para la API y aplica controles de acceso por usuario y empresa. Ningun sistema es completamente infalible, pero trabajamos para reducir riesgos razonables de acceso no autorizado.

Conservacion y eliminacion

Conservamos la informacion mientras la cuenta o los recursos asociados sigan activos. El usuario puede editar o eliminar empresas, tarjetas y guardados desde las herramientas disponibles. Para solicitudes adicionales, puede contactarnos.

Contacto

Para preguntas de privacidad o solicitudes relacionadas con datos, contacta al equipo desde la pagina de contacto de Cardbook.
