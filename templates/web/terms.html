Terminos

Terminos de uso

Estos terminos describen las reglas basicas para usar Cardbook, su API, web y app movil.

Uso del servicio

Cardbook permite crear y administrar tarjetas digitales, perfiles de negocio, tarjetas de presentacion, empresas, alianzas y contactos guardados. El usuario es responsable de la informacion que publica o comparte.

Cuentas

El usuario debe mantener sus credenciales seguras y usar informacion veraz cuando cree empresas, perfiles o tarjetas. Cardbook puede restringir el acceso si detecta abuso, uso fraudulento o actividad que afecte a otros usuarios.

Contenido publico

Las tarjetas y perfiles compartidos mediante enlaces o codigos QR pueden ser visibles publicamente. El usuario debe tener permiso para publicar logos, imagenes, datos de contacto, nombres comerciales y cualquier contenido incluido.

Uso aceptable

No se permite usar Cardbook para suplantacion, spam, distribucion de contenido ilegal, abuso de la API, intentos de acceso no autorizado o actividad que comprometa la seguridad del servicio.

Disponibilidad

Trabajamos para mantener Cardbook disponible, pero no garantizamos disponibilidad continua o libre de errores. El servicio puede cambiar, mejorar o suspender funciones segun necesidades tecnicas o comerciales.

Limitacion

Cardbook se ofrece como herramienta de gestion y presencia digital. El usuario acepta que usa el servicio bajo su responsabilidad y que debe validar la informacion antes de compartirla comercialmente.

Contacto

Para dudas sobre estos terminos, utiliza la pagina de contacto de Cardbook.
